# 0005. マルチフォーマット画像抽出と Windows COM 連携戦略

* Status: Accepted
* Date: 2026-08-12

## Context (背景)

マルチモーダル VLM（Claude, Gemini 等）の登場に伴い、ドキュメント内の図解、システム構成図、フローチャートなどの視覚情報を正確に AI に認識させる必要性が高まった。

## Decision (決定事項)

フォーマット特性に応じた最適なレンダリング手法を採用した：

1. **PDF**: `go-fitz` (MuPDF CGO 静的リンク) により、爆速かつ高品質なスライドレンダリング・画像抽出を実現。
2. **PowerPoint**: フォントとレイアウトの完全な再現性を担保するため、Windows 環境での `go-ole` (PowerPoint COM) 連携による画像エクスポートを採用。
3. **Excel**: クリップボード競合を回避し、かつ巨大な表・図を1ページ幅に美しく収めるため、`go-ole` 経由の `Fit-to-Page` 印刷設定＋PDF画像化パイプラインを採用。
4. **Handle-based Interface**: 出力先ディレクトリへの画像生成とファイルパス返却を一括で行い、エージェントのコンテキスト消費を最小化。

## Consequences (影響と結果)

### メリット
- AI が図解や複雑なレイアウトを直接視認・分析可能に。
- 外部ツール不要の自動パイプラインにより、安定したバッチ処理が可能。

### デメリット / 制約
- PowerPoint および Excel の画像化機能は Windows かつ Microsoft Office がインストールされた環境に依存する。
