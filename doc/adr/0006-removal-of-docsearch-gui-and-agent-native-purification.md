# 0006. docsearch-gui の廃止と Agent-Native CLI への純化

- ステータス: 承認済み (Accepted)
- 日付: 2026-11-22

## コンテキスト (Context)
これまで本プロジェクトでは、AI エージェント向けの特注 CLI（`doctools-cli.exe`）に加え、人間向けのデスクトップ全文検索ツール（`docsearch-gui.exe`）を同一リポジトリ内の Multi-Binary 構成として保守・開発してきた。
しかし、人間向けデスクトップツールを同居させることにより、以下の深刻な問題が発生していた：
1. **プラットフォーム・アーキテクチャの肥大化**: Win32 低レベルキーフック、タスクトレイ常駐、SSE による同一タブ制御、ネイティブ小窓描画など、AI エージェントの自律運用に無関係な OS 特化コードが大量に混入。
2. **CGO 依存の漏れ出し**: `pkg/fts` に MuPDF CGO インデクサが同居していたため、本来 CGO フリーで軽量に保つべき GUI バイナリ側にも CGO 静的リンクが強制されていた。
3. **テストカバレッジと保守性の低下**: GUI の非同期イベントや OS フックの網羅が困難であり、パッケージカバレッジが 90% 未満に悪化。
4. **仕様ドリフトとシャドウ要件**: GUI の UX 改善タスクが先行し、要件定義書に存在しない `DOCSEARCH-10〜16` やゴースト完了タスクが混入する原因となっていた。

## 決定 (Decision)
`cmd/docsearch-gui` および `pkg/docsearch` をリポジトリから完全に廃止・削除する。
本プロジェクトを本来の「シングルバイナリ・ゼロ依存の Agent-Native CLI (`doctools-cli.exe`)」へ一本化し、ドキュメント解析・変換・FTS エンジンの高速性と決定論性に 100% 集中する。

## 結果 (Consequences)
### ポジティブ
- コードベースが大幅にスリム化され、ビルド・テスト・CI が劇的に高速化。
- 不要な Windows 固有依存関係が排除され、純粋な CLI ツールとして可搬性が向上。
- 要件定義・設計書・タスク台帳の整合性が回復し、仕様ドリフトの温床が根絶。
- 全テストカバレッジが 90% 以上へ回復。

### ネガティブ / トレードオフ
- 人間がデスクトップ通知トレイや Ctrl 連打からブラウザ検索画面を直接呼び出すデスクトップ GUI 機能は提供されなくなる（必要に応じて別リポジトリのフロントエンド専業ツールとして再設計可能）。
