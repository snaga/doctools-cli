# 0003. Excel セル単位 Diff 抽出および安全ガードレール付き Patch 適用機構

* Status: Accepted
* Date: 2026-08-12

## Context (背景)

AI エージェントが Excel 設計書やデータシートを修正する際、従来の「ファイル全体の上書き」や「CSV 経由の変換」では以下の重大なリスクが存在していた：

1. **セルの意図しない破壊**: AI が想定していないセルや数式、結合セルが巻き込まれて破壊される。
2. **競合の検出不能**: 修正元ファイルが人間によって編集されていた場合、古い状態を前提としたパッチが誤適用される。
3. **安全な事前検証手段の欠如**: 変更が適用される前に差分をプレビューする標準的な仕組みがなかった。

## Decision (決定事項)

`qax-os/excelize` を活用し、**セル番地レベルの決定論的 Diff 抽出 (`excel diff`)** と **安全ガードレール付き Patch 適用 (`excel patch`)** を実装した。

1. **セル単位の決定論的 Diff (`excel diff`)**:
   - シート名・セル番地・型・変更前後の値を構造化 JSON で過不足なく抽出。
2. **安全ガードレール付き Patch (`excel patch`)**:
   - **Old-Value 検証**: パッチ内の `old_value` が現在のセルの値と一致しない場合、適用を中止してエラーを報告（ガードレール）。
   - **自動バックアップ**: パッチ適用直前のファイルをタイムスタンプ付きで自動退避 (`--backup`)。
   - **ドライラン対応**: `--dry-run` フラグにより、実際にファイルを書き換えることなく適用可否と監査ログを事前プレビュー。
   - **結合セル保護**: 結合セル（Merged Cells）への書き込み時は代表セル（左上）を安全に解決。

## Consequences (影響と結果)

### メリット
- AI による Excel ファイルの編集・修正が 100% 決定論的かつ安全に行えるようになった。
- 差分監査ログ（Audit Log）が JSON で出力され、変更履歴の追跡が極めて容易。

### デメリット / 制約
- 大規模なセル（数万セル以上）の全走査 Diff はメモリと時間を消費するため、シート指定オプションによるスコープ制限が推奨される。
