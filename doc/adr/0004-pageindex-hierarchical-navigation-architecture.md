# 0004. PageIndex 階層ナビゲーション構造の導入

* Status: Accepted
* Date: 2026-08-12

## Context (背景)

数百ページ規模の長大な PDF や PowerPoint プレゼンテーションにおいて、AI エージェントが全体の構造を把握し、必要なセクションを効率的に探索するためのナビゲーション地図（目次・ツリー構造）が求められていた。

## Decision (決定事項)

ドキュメントの章・節・項（またはスライド階層）をツリー構造化した **「PageIndex」** アーキテクチャを導入した。

1. **ツリーナビゲーション (`pageindex tree`)**:
   - ドキュメント全体の構造を階層ツリーとして探索（深さ指定・ノード指定対応）。
2. **ピンポイント取得 (`pageindex content`)**:
   - 目的のノード ID を指定して、該当セクションのみを抽出。
3. **独立メタデータ管理**:
   - `<filename>.pageindex.json` として対象ファイルと同階層で 1 対 1 管理。

## Consequences (影響と結果)

### メリット
- 長大なドキュメントの全体像を最小限のトークンで素早く把握可能。
- 必要な箇所のみを部分取得できるため、コンテキストウィンドウの枯渇を防止。
